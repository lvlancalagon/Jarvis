# JARVIS - Продвинутый цифровой помощник

Это расширенная реализация JARVIS, вдохновленная фильмами Marvel.

## Новые возможности (v2.0)
- **Глубокий мониторинг**: Теперь JARVIS отслеживает не только ЦП и память, но и состояние диска и сетевое соединение.
- **Анализ проекта**: Команда "проект" позволяет JARVIS просканировать текущую директорию и вывести структуру файлов.
- **Боевые протоколы**: Добавлены пасхалки, такие как "Протокол House Party" и "Clean Slate".
- **Безопасность**: Команда сканирования систем на наличие угроз.
- **Симуляция поиска**: Возможность инициировать поиск информации (требует сетевого соединения).

## Как запустить
Для запуска JARVIS выполните команду:
```bash
python3 jarvis/main.py
```

## Доступные команды
- **привет / hello**: Приветствие от JARVIS.
- **статус / система**: Детальный отчет о состоянии систем (ЦП, Память, Диск, Сеть).
- **проект / файлы**: Анализ структуры текущего проекта.
- **время / дата**: Текущее время и дата.
- **протокол [название]**: Активация спец. протоколов (например, "house party").
- **сканируй / безопасность**: Проверка систем безопасности.
- **узнай [запрос] / поиск [запрос]**: Поиск информации.
- **кто ты**: Информация о помощнике.
- **выход / пока**: Завершение работы.

## Голосовые ответы
Каждая реплика JARVIS сохраняется в файл `response.mp3`. На старте JARVIS автоматически делает краткий доклад о состоянии систем.
