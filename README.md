# JARVIS - Цифровой помощник

Это реализация JARVIS, вдохновленная фильмами "Железный человек".

## Особенности
- **Голосовые ответы**: Каждая реплика JARVIS сохраняется в файл `response.mp3` с использованием Google Text-to-Speech (gTTS).
- **Мониторинг системы**: JARVIS может сообщать о загрузке процессора и использовании памяти.
- **Информация о времени**: Помощник знает текущее время и дату.
- **Персонализация**: JARVIS обращается к вам "сэр" и имеет вежливую манеру общения.

## Как запустить
Для запуска JARVIS выполните команду:
```bash
python3 jarvis/main.py
```

## Доступные команды
- **привет / hello**: Приветствие от JARVIS.
- **статус / система**: Информация о состоянии систем (ЦП, Память).
- **время / дата**: Текущее время и дата.
- **кто ты**: Информация о помощнике.
- **выход / пока**: Завершение работы.

## Зависимости
Для работы требуются библиотеки `gTTS` и `psutil`. Они уже установлены в текущем окружении.
