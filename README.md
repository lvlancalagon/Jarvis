# JARVIS - Персонализированный цифровой помощник

Это продвинутая реализация JARVIS, адаптированная под ваши профессиональные задачи.

## Новые возможности (v3.0 - Специализированный выпуск)
- **Помощник тестировщика**: Команда `тестирование` или `чек-лист` выводит структурированные списки для мануального тестирования сайтов (UI/UX, Функционал, Кросс-браузерность).
- **YouTube Менеджер**: Команды `контент`, `ютуб` или `идеи` генерируют идеи для видео и теги для ваших каналов (GMod, Sprunki, Italian Brainrot).
- **Сетка каналов**: Команда `совет` дает рекомендации по управлению большим количеством каналов.
- **Индивидуальный подход**: JARVIS знает о ваших занятиях и адаптирует свои ответы и приветствия.

## Основные возможности
- **Глубокий мониторинг**: Отслеживание ЦП, памяти, диска и сети.
- **Анализ проекта**: Команда `проект` сканирует структуру файлов.
- **Боевые протоколы**: "House Party" и "Clean Slate".
- **Голосовые ответы**: Все реплики сохраняются в `response.mp3`.

## Как запустить
```bash
python3 jarvis/main.py
```

## Доступные команды
- **тестирование / чек-лист**: Списки проверок для QA.
- **контент / идеи / ютуб**: План контента для GMod, Sprunki и Brainrot.
- **канал / совет**: Советы по ведению YouTube каналов.
- **статус / система**: Отчет о состоянии системы.
- **проект / файлы**: Структура текущего проекта.
- **кто ты**: Информация о персонализации JARVIS.
- **выход / пока**: Завершение работы.
